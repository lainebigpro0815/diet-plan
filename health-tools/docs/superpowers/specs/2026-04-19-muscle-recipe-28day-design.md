# 增肌食谱28天改造设计

## 目标
将增肌食谱从7天扩展到28天，引入碳循环的食物选择逻辑，修复甜玉米数据。

## 修改范围

### 1. 训练表28天展开
- 当前表头7列（周一~周日），改为28列（第1天~第28天）
- 训练部位行按选定模式（练1休1等）展开28天
- 碳水/蛋白质/脂肪/热量/盈余 行同步展开

### 2. 食物选择面板改造
- 移除当前无食物选择的硬编码模式
- 新增碳循环风格的分类Tab面板：碳水来源、蛋白质来源、脂肪来源
- 每个分类多选，点击即选/取消
- 默认选中一组食物（参考碳循环默认值）
- 保存到localStorage

### 3. 食谱生成逻辑
- 28天每天食物不同，使用 round-robin (dayIndex % pool.length) 轮换
- 每餐从选中池中按天索引取食物
- 保留生/熟重切换
- 保留餐数选择（3/4/5餐）
- 保留高蛋白/标准食谱类型

### 4. 甜玉米数据修复
- `unitWeight: 1` → `unitWeight: 250`
- `cookedCarbs: 38` → `cookedCarbs: 28`（熟后吸水，碳水密度降低）
- 保持 `unit: "根"`, `carbs: 38`

### 5. Excel下载
- 表头改为28列
- 食谱导出也改为28天

## 参考碳循环的关键逻辑
- `pickFromPool(pool, index)` → `pool[index % pool.length]`
- 食物分类：carb/protein/fat（用category字段）
- 选中状态存储为数组：`{carb: [...], protein: [...], fat: [...]}`

## 风险点
- 文件较大（1400+行），需小心编辑
- 食谱表28列可能溢出屏幕，需保持横向滚动
- 鸡蛋按个计算的特殊逻辑需保留
