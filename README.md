# 阿亮健身 - 饮食计划

健身营养工具整合平台，提供多种科学饮食计划方案的交互式 HTML 工具。

## 🛠 工具列表

| 工具 | 说明 |
|------|------|
| **5+2轻断食** | 5天正常饮食 + 2天低热量饮食的间歇性断食方案 |
| **碳循环食谱** | 一个月的高碳/低碳循环饮食计划 |
| **532碳水渐减食谱** | 逐步减少碳水化合物摄入的渐进式方案 |
| **增肌食谱** | 针对增肌目标的营养配餐方案 |

## 🚀 使用方式

直接在浏览器中打开 `health-tools/index.html`，通过标签页切换不同工具。

或者单独打开各个 HTML 文件：
- `health-tools/5+2轻断食.html`
- `health-tools/碳循环一月食谱(1).html`
- `health-tools/532碳水渐减食谱.html`
- `health-tools/增肌食谱(1).html`
